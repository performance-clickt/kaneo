# Pyrito Register surface lockups

Canonical surface family, version 1.2.0.

- Surfaces: Wiki, Ops, Design
- System: The Register
- Light SVGs: Ink wordmark and label for white or light surfaces
- Dark SVGs: off-white wordmark and label for Ink or Abyss surfaces
- D20 geometry and colors remain fixed
- Surface name is an uppercase Paper Mono identifier
- Teal rule and Ember square are fixed parts of the lockup

The SVGs contain embedded font assets and use transparent backgrounds. Do not recolor, rearrange, or substitute the Register treatment.
